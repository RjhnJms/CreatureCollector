Press Start 2P for the HUD. Pixelify Sans for questions, so kids can read them.

Why it works

  • Instantly reads as a "real game" to kids
  • Pixel art is quick to make and easy to keep consistent
  • Tiny file sizes, so it runs well on cheap phones

Watch out for

  • Can look like a Pokémon copy, so the layout needs its own twist
  • Pixel fonts are hard to read for Grade 1–2, so keep questions in a clear font
