# Creature Collector

A paper-craft learning game for elementary kids about Philippine wildlife.
Explore five places, find creatures with a magnifying glass by day or a
flashlight at night, and answer questions to add them to your Dex.

## Download (Android)

**[Download the latest APK](https://github.com/RjhnJms/CreatureCollector/releases/latest/download/creature-collector.apk)**

1. Open the link on your Android phone.
2. When the download finishes, tap the file to install it. If asked, allow
   your browser to install unknown apps.

All releases are listed on the [Releases page](https://github.com/RjhnJms/CreatureCollector/releases).

## What's inside

- **5 maps:** Rainforest, Ocean, Rice Terraces, Mangrove, and Cave
- **30 creatures** and 300 questions (5 asked per play)
- **Day and night scenes** that follow the clock, or can be set in Settings
- **Real animal calls** for some birds, and a "Silent" note for creatures that
  make no sound
- **Badges with gem rewards**, a shop with outfits, and a practice mode for
  questions you missed
- **Kid-friendly settings:** read aloud, text size, calm motion, and a break
  reminder

## Build it yourself

You need [Flutter](https://docs.flutter.dev/get-started/install).

```bash
flutter pub get
flutter run
```

To build an Android APK:

```bash
flutter build apk --release
```

Run the tests with `flutter test`.
